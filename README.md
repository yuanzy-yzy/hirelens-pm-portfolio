# HireLens AI：技术人才招聘助手

HireLens AI 是一个面向 AI、具身智能及其他技术团队招聘场景的产品经理作品集项目。项目聚焦“岗位需求难以结构化、技术简历筛选成本高、判断依据不透明”三个问题，提供 JD 解析、简历匹配、证据解释、风险提示和面试问题生成能力。

本仓库用于完整保留产品研究、需求决策、数据分析、PRD、指标体系、评测集和可运行原型，便于项目复盘和后续迭代。

## 项目目标

- 将模糊 JD 转换为可核验的岗位能力模型。
- 将候选人经历与岗位要求逐项对齐，展示匹配证据和信息缺口。
- 为招聘人员生成有针对性的核验问题，同时保留人工决策权。
- 用规则基线与大模型方案进行对照，评估匹配质量、稳定性和成本。

## 仓库结构

```text
data/          公开岗位样本、数据来源和字段字典
research/      用户场景、岗位市场研究和能力模型
product/       用户旅程、竞品分析、需求池、PRD、指标与 AI 协议
evaluation/    测试集设计及人工标注用例
outputs/       岗位市场分析工作簿与可视化预览
prototype/     产品原型说明和 HireLens Web 可运行代码
scripts/       数据处理与分析工作簿生成脚本
portfolio/     产品案例说明、演示脚本和面试追问答案
```

## 数据与合规边界

- 岗位数据来自公开页面，并在 `data/sources.md` 中记录来源。
- 测试简历仅使用本人材料、明确授权且脱敏的材料或人工构造样本。
- 仓库不包含公司内部简历、候选人隐私、平台登录凭证或 API 密钥。
- 不绕过招聘平台的验证码、访问限制或反爬机制。
- 自动搜索候选人属于后续路线图能力，只有获得官方 API 或平台授权后才接入。
- Demo 和测试结果不包装为真实线上业务成果。

## 运行 Web 原型

环境要求：Node.js 22.13.0 或更高版本。

```bash
cd prototype/hirelens-web
npm install
npm run dev
```

浏览器访问终端显示的本地地址即可。

## 规则基线状态

- 状态枚举：满足、部分满足、未发现、矛盾、待核验
- 当前测试集：20 条人工构造、脱敏判断
- 模型成本：0 元（纯本地规则）
- 结果说明：当前评测只能证明规则流程可运行，不能解释为真实招聘业务准确率

运行评测：

```bash
node evaluation/run_rule_evaluation.mjs
```

## 项目性质
