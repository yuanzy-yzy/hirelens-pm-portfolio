# HireLens AI 演示视频

本目录包含用于求职展示的 HireLens AI 产品演示视频及其可编辑源文件。

## 文件说明

- `HireLens_AI_演示视频.mp4`：约 56 秒的字幕式产品演示视频，可直接发送给面试官或放入作品集。
- `HireLens_AI_演示视频源文件.pptx`：可编辑演示文稿源文件，后续可以替换岗位样本、截图或品牌信息后重新导出。
- `HireLens_AI_演示视频旁白稿.txt`：配套口语讲解稿，可用于面试现场讲解或后续录制配音。

## 展示口径

视频展示的是当前个人作品集 Demo：规则基线版本支持 JD 与脱敏简历输入、岗位画像、匹配状态、证据、风险和面试追问。当前版本未接入大模型、招聘平台 API 或真实候选人隐私数据，也不代表已经商业化上线或产生真实招聘业务效果。

## 建议使用方式

简历中优先放在线 Demo 或 GitHub 链接；视频作为补充材料。面试时可按“问题场景 → 产品流程 → 结果解释 → 规则实现 → 后续接入大模型”的顺序讲解。
