# HireLens 离线演示截图

更新时间：2026-07-30

这组截图用于本地开发服务无法启动或面试现场网络不稳定时，按照固定顺序完成项目讲解。页面全部使用人工构造、脱敏的测试数据，不包含真实候选人个人信息。

## 演示顺序

1. `01_候选人排序.png`
   - 说明系统基于统一岗位标准对 5 份测试简历进行辅助排序。
   - 强调分数不是录用结论，最终决定由招聘人员作出。
2. `02_岗位画像.png`
   - 说明如何把 JD 拆解成必备项、核心能力、加分项和待澄清问题。
   - 强调岗位画像需由 HR 和业务负责人确认。
3. `04_规则实验室运行结果.png`
   - 说明当前可运行版本是本地规则基线。
   - 展示匹配分、逐项证据、判断理由、置信度、风险和面试核验问题。
4. `03_评估记录.png`
   - 说明 18/20 只代表当前人工构造测试集状态一致，不能解释为真实业务准确率。
   - 主动说明下一轮需要盲测样本、第二标注者和大模型对照实验。

## 对外表述边界

- 可以说：完成了可运行的规则匹配 MVP、评测基线和大模型混合方案设计。
- 不应说：系统已接入招聘平台、已服务真实企业、已使用真实候选人数据或准确率达到 100%。
- 当前混合模式尚未接入大模型；自动搜索候选人依赖招聘平台官方授权接口，不属于当前 MVP。
