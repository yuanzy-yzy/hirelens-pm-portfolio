# HireLens AI 原型说明

版本：v0.1  
日期：2026-07-23

## 当前状态

- 已完成可点击网页原型；
- 已通过生产构建；
- 当前使用人工构造的测试候选人和模拟分析结果；
- 尚未接入真实大模型或真实候选人数据；
- 私有站点已创建，但源码推送授权未通过，因此未发布线上地址。

## 原型展示内容

1. 嵌入式工程师招聘项目；
2. 岗位画像、简历解析、匹配分析和人工复核四步流程；
3. 5 名测试候选人的排序；
4. 必备项通过情况和主要风险；
5. 逐项匹配证据、判断理由与面试问题；
6. 准确、不准确、待面试确认的人工反馈入口；
7. 岗位画像权重；
8. 规则模式/混合模式切换；
9. 模型评估记录；
10. 测试数据与非业务结果提示。

## 已实现交互

- 切换规则模式和混合模式；
- 切换候选人；
- 展开要求对应的证据；
- 切换候选人、岗位画像和评估记录页面；
- 展示不同候选人的匹配分与风险。

## 尚未实现

- PDF/DOCX 真正上传和解析；
- 真实规则引擎；
- 大模型 API 调用；
- 真实评分和重新计算；
- 反馈持久化；
- 报告导出；
- 用户登录和企业权限；
- 招聘平台或 ATS 接口。

## 下一开发入口

1. 将测试岗位和候选人数据迁移为独立 JSON；
2. 实现岗位要求与简历文本的规则匹配函数；
3. 接入文件文本提取；
4. 接入可配置的大模型接口；
5. 使用 `test_cases_v0.1.csv` 做自动评估；
6. 将真实计算结果替换页面中的模拟结果；
7. 在获得发布授权后重新推送并部署私有演示站点。
