# 功能架构与核心流程

版本：v0.1  
日期：2026-07-23

## MVP 功能架构

### 1. 岗位工作台

- JD 粘贴；
- 岗位信息提取；
- 必备项/加分项分类；
- 权重编辑；
- 待澄清问题；
- 岗位画像确认。

### 2. 候选人工作台

- PDF/DOCX 上传；
- 文本解析与脱敏提示；
- 批量导入；
- 候选人列表；
- 文件删除。

### 3. 匹配引擎

- 硬条件规则；
- 技能同义词归一；
- 大模型语义证据提取；
- 要求—证据逐项判断；
- 综合分数与置信度；
- 冲突和缺失检测。

### 4. 分析报告

- 候选人排序；
- 匹配项、部分匹配项、缺口和待核验项；
- 原文证据；
- 判断理由；
- 面试问题；
- 候选人横向对比；
- 结果导出。

### 5. 人工校准

- 判断准确/不准确/待核验；
- 修改证据；
- 修改岗位权重；
- 记录 bad case；
- 重新计算结果。

### 6. 系统设置

- 模型接口配置；
- 规则模式/混合模式切换；
- 数据保留设置；
- 测试数据模式；
- 使用说明和风险提示。

## 页面结构

1. 首页/项目列表；
2. 新建岗位；
3. 岗位画像确认；
4. 简历上传；
5. 分析进度；
6. 候选人列表；
7. 候选人详情；
8. 候选人对比；
9. 模型评估与 bad case；
10. 设置。

## 核心流程

```text
新建岗位
  → 输入JD
  → 生成岗位画像
  → HR确认权重
  → 导入脱敏简历
  → 规则校验
  → 大模型语义分析
  → 候选人排序
  → 查看证据与缺口
  → 生成面试问题
  → 人工反馈
  → 导出报告
```

## 关键异常流程

- JD 太短：提示补充职责、年限、必备技能和交付目标。
- 简历无法解析：保留原文件并允许粘贴文本，不生成无依据判断。
- 模型调用失败：切换规则基线并明确标识。
- 找不到证据：返回“未发现”，不得推断为“不具备”。
- 条件相互冲突：提示 HR 重新确认岗位画像。
- 候选人含敏感字段：默认不参与评分，并提示脱敏。
- 多份简历同分：展示关键证据差异，不强行排序。

## 决策原则

- 证据优先于总分；
- “未发现”不等于“不具备”；
- AI 只辅助，不自动淘汰；
- 硬条件由规则处理，模糊能力由模型处理；
- 所有模型输出必须通过结构化格式校验；
- 用户可以看到并修正判断依据。
