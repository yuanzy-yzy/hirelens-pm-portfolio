# AI 输入输出协议

版本：v0.1  
日期：2026-07-23

## 架构原则

1. 规则先行：学历、年限、地点和明确必备技能优先使用确定性逻辑。
2. 证据约束：模型只能基于提供的 JD 和简历文本判断。
3. 结构化输出：所有结果必须通过 Schema 校验。
4. 不确定性显式化：没有证据时输出“未发现”或“待核验”。
5. 人工最终决定：模型不得输出“录用”“淘汰”等最终决策。

## 枚举约束

- `type`: `required`、`core`、`bonus`
- `status`: `met`、`partial`、`not_found`、`conflict`、`verify`
- `confidence`: 0—1

## 禁止行为

- 根据学校、年龄、性别、民族、婚育等非必要属性推断能力；
- 把未提及的信息写成候选人不具备；
- 生成简历中不存在的项目、技能、年限或结果；
- 仅返回总分而不给证据；
- 输出录用、淘汰等最终决策；
- 引用无法在原文定位的证据。

## 校验与降级

- JSON 无法解析：重试一次，并仅要求修复格式；
- Schema 不通过：保留错误日志，切换规则结果；
- 引用文本不存在：该项降级为 `verify`；
- 模型不可用：使用规则基线，界面明确标记“规则模式”；
- 多次失败：停止调用并提示用户，不循环消耗 Token。
